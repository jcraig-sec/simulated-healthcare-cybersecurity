# Simulated Healthcare Cybersecurity Portfolio

## Overview

This repository contains cybersecurity case studies developed for simulated healthcare environments. The projects examine security challenges involving network architecture, identity and access management, incident response, medical devices, cloud services, and Zero Trust principles.

## Case Studies

### [Zero Trust Network Segmentation Design](zero-trust-network-design/)

Designed a three-zone micro-segmentation architecture separating clinical systems, Internet of Medical Things devices, and facilities/operational technology. The design uses Azure security controls to restrict unnecessary communication and reduce lateral movement.

**Topics:** Zero Trust, network segmentation, Azure NSGs, Azure ASGs, Azure Firewall, Microsoft Defender for IoT

### [Identity Threat Detection and Incident Response Playbook](identity-threat-response-playbook/)

Developed detection conditions and a NIST-aligned response process for unauthorized device access, suspicious administrative traffic, and privileged-account compromise across simulated clinical 5G trust boundaries.

**Topics:** Incident response, identity security, NIST SP 800-61, 5G security, evidence preservation

### IAM and IoT Security Audit

Assessed identity and device-security weaknesses involving excessive access, authentication practices, shared accounts, and exposed remote administration. Recommended controls using Microsoft Entra ID, RBAC, Conditional Access, and Azure Bastion.

**Topics:** IAM, IoT security, RBAC, MFA, Conditional Access, Azure Bastion

### SASE and ZTNA Migration Strategy

Evaluated a migration from legacy VPN access toward identity-aware Zero Trust Network Access and cloud-delivered security controls.

**Topics:** SASE, ZTNA, Microsoft Entra Private Access, SPIFFE/SPIRE, remote access security

## Skills Demonstrated

## Disclaimer

All projects in this repository are educational case studies based on simulated healthcare environments. They contain no real patient information, production configurations, or proprietary organizational data.
